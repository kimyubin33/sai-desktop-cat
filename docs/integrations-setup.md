# 외부 연결 설정 (Telegram · Google 캘린더 · Google 할 일)

모든 연결은 **설정 → 외부 연결**에서 합니다. 화면에는 각 연결의 실제 상태(연결됨/안 됨), 마지막 결과, 오류를 그대로 보여 줍니다.

## 무엇이 어디로 가는가

| 연결 | 보내거나 읽는 것 | 보내지 않는 것 |
|---|---|---|
| Telegram | 배정 제안, 막힘 도움 요청, 팀 약속 제안, 자리를 비웠을 때의 내 진행 확인 | 개인 대화, 정리 카드, 받은 조언 주제 |
| Google 캘린더 | 바쁜 시간(free/busy)만 읽음, 내가 누른 작업만 일정으로 추가 | 일정 제목·내용·참석자 (읽을 권한 자체를 요청하지 않음) |
| Google 할 일 | 내가 수락한 작업만 "사이 · 프로젝트" 목록에 올리고 완료 상태를 맞춤 | 다른 사람 작업, 수락 전 작업 |

캘린더로 계산한 빈 시간은 이 컴퓨터에서만 보여 주는 참고값입니다. 팀에 보이는 것은 본인이 확인해 저장한 "주간 가능 시간" 숫자뿐입니다.

## Telegram

**팀에서 한 명만: 봇 만들기**
1. Telegram 에서 **@BotFather** → `/newbot` → 이름(예: 사이) → `bot` 으로 끝나는 아이디(예: `saigajoa_bot`).
2. 받은 토큰을 **설정 → 외부 연결 → Telegram**에 넣고 **봇 저장**. 토큰은 Firestore 에 팀원만 읽을 수 있게 저장됩니다 (보안 규칙 `integrations`).
   토큰은 채팅이나 저장소에 올리지 마세요.

**팀원 각자: 내 Telegram 연결**
1. **Telegram 연결하기**를 누르면 봇 대화가 열립니다.
2. 아래쪽 **시작(Start)** 을 누르면 몇 초 안에 앱이 연결을 확인하고 "연결됐어요" 메시지를 보냅니다.
3. 옵션
   - **팀 알림 받기**: 배정 제안, 도움 요청, 팀 약속 제안
   - **자리를 비웠을 때 진행 확인을 Telegram 으로**: 10분 넘게 입력이 없거나 화면이 잠겨 있으면 말풍선 대신 Telegram 으로 보냅니다. 조용한 모드·집중 모드·방해 금지 시간은 그대로 지킵니다.
4. **시험 메시지 보내기**로 확인할 수 있습니다.

연결 방식: 앱이 1회용 코드를 만들고, 봇에 들어온 `/start 코드` 메시지를 찾아 내 채팅을 연결합니다. 사이에는 서버가 없어서 봇이 대답하지는 않습니다. 팀원 앱끼리 서로의 연결 메시지를 지우지 않도록 읽기만 합니다.

## Google 캘린더 · 할 일

**한 번만: OAuth 클라이언트 만들기** (Google Cloud 콘솔, 프로젝트 `saigajoa`)
1. **API 및 서비스 → 라이브러리**: Google Calendar API, Google Tasks API 사용.
2. **Google 인증 플랫폼(OAuth 동의 화면)**: 앱 이름 `사이`, 대상 **외부**. **대상 → 테스트 사용자**에 팀원 Gmail 을 모두 추가.
3. **클라이언트 → 클라이언트 만들기 → 데스크톱 앱**. 클라이언트 ID 와 보안 비밀번호를 다음 중 한 곳에 넣습니다.
   - 앱의 **설정 → 외부 연결 → Google**에 붙여 넣기 (팀원 각자, 가장 간단)
   - `config/google-client.json` 파일로 저장 (형식은 `config/README.md`). 이 파일이 있으면 앱이 자동으로 쓰고, 설치 파일을 만들 때도 함께 들어갑니다.

   GitHub 의 비밀 정보 차단(push protection) 때문에 이 값은 저장소에 올리지 않습니다. 데스크톱 앱용 보안 비밀번호는 Google 도 비밀로 취급하지 않지만, 팀 밖에 퍼뜨릴 필요는 없습니다.

**팀원 각자: 로그인**
- **Google 로 로그인** → 브라우저에서 로그인·권한 허용 → 자동으로 돌아옵니다 (`127.0.0.1` 의 임시 주소로 받음).
- 테스트 상태의 앱은 약 7일마다 로그인이 풀립니다. 풀리면 외부 연결에 "다시 로그인" 안내가 뜹니다.

**쓰는 곳**
- 협업 탭 → 자기소개 → **Google 캘린더로 빈 시간 보기**: 앞으로 7일과 마감까지의 빈 시간(9~22시)을 보여 주고, 그 40%를 가능 시간으로 적을지 제안합니다. 저장은 본인이 합니다.
- 협업 탭 → 내 작업 → **캘린더에 작업 시간 잡기**: 2주 안의 첫 빈 틈에 최대 2시간 블록을 "사이: 작업 이름" 일정으로 넣습니다. 더 필요하면 한 번 더 누르면 다음 빈 틈에 잡습니다.
- 할 일 동기화 (팀 동기화 때 자동, 또는 **할 일 지금 동기화**)
  - 내가 수락한 작업 → "사이 · 프로젝트 이름" 목록에 추가 (마감일 포함)
  - 어느 쪽에서든 완료하면 다른 쪽도 완료 (사이 쪽 완료는 팀에 보입니다)
  - 제목은 사이 쪽이 기준
  - Google 에서 지운 할 일은 다시 만들지 않습니다
  - 같은 작업을 두 번 올리지 않도록 연결표를 이 컴퓨터에 보관합니다

## 확인 상태

- 단위 테스트: Telegram 요청 형식·연결 코드·보낼 수 있는 알림 종류, OAuth(PKCE·코드 교환·갱신·만료), 빈 시간·작업 시간 계산, 할 일 양방향 동기화를 가짜 서버로 검사합니다.
- 보안 규칙: `integrations`, `telegram` 규칙은 `npm run check:firebase` 의 검사 항목에 포함됩니다 (규칙을 다시 게시한 뒤 실행).
- 실제 Telegram 봇과 Google 계정으로는 아직 확인하지 않았습니다. 설정 화면의 **시험 메시지 보내기**, **할 일 지금 동기화**로 확인해 주세요.
