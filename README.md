# 사이 — 고양이 협업 도우미

각 팀원의 바탕화면을 돌아다니는 고양이 **사이**가 평소에는 짧은 조언을 건네고, 팀원 때문에 속상한 이야기를 들어 주며 감정·사실·추측을 나눠 정리하는 데스크톱 앱입니다. 정리된 고민은 원문 없이 **일반 주제**로만 바뀌어, 다음 단계에서 상대의 고양이가 평소 조언 속에 자연스럽게 섞어 말하게 됩니다.

개발 방향은 [docs/development-direction.md](docs/development-direction.md)를 따릅니다. 이 저장소는 그 문서의 **1~2단계**(경험 시제품 + 개인 대화)를 구현한 상태입니다.

## 실행

```bash
npm install
npm start        # 개발 실행
npm test         # 핵심 로직 테스트 (Electron 없이 Node만으로 실행)
npm run dist:win # Windows 설치 파일·포터블 exe 만들기 (Windows에서 실행 권장)
```

Windows를 우선 대상으로 만들었고, macOS·Linux에서도 실행됩니다 (Linux는 투명 부분 클릭 통과가 제한될 수 있음).

## 지금 할 수 있는 것

**바탕화면 고양이 (1단계)**
- 작업 표시줄 위를 걷고, 앉고, 식빵 자세로 쉬고, 잠듭니다. 도트 그림은 코드로 그려서 외부 이미지가 없습니다.
- 끌어서 옮길 수 있고, 놓으면 바닥으로 내려와 앉습니다. 다른 모니터로도 옮길 수 있습니다.
- 고양이를 클릭하면 대화창, 오른쪽 클릭하면 메뉴가 열립니다. 투명한 부분은 클릭이 아래 창으로 통과합니다.
- 평소에 일상 한마디·생각거리·협업 조언·고전 문장을 말풍선으로 건넵니다.
  - 사이가 직접 쓴 문장은 `사이의 한마디`로, 고전·속담은 출전(예: 『논어』 위정편)으로 표시합니다. 출처가 불확실한 "유명인 명언"은 넣지 않았습니다.
- 말풍선마다 **닫기 · 나중에 · 이런 말 줄이기 · 이야기하기**가 있고, 최근 한 말은 반복하지 않습니다.
- 트레이·오른쪽 클릭 메뉴: 조언 한마디 듣기, 조용한 모드, 집중 모드(30분/1시간/2시간), 말 거는 빈도, 숨기기.
- 설정: 방해 금지 시간(자정 넘김 지원), "이런 말 줄이기" 기록 초기화.

**개인 대화 (2단계)**
- 대화 시작 시 고르기: 팀원 일로 속상해요 / 내 사정을 이야기하고 싶어요 / 그냥 이야기할래요.
- 속상한 이야기는 `감정 알아주기 → 어떤 약속·기대였는지 → 서로 확인한 약속이었는지·상대 사정 → 실제 영향 → 바라는 것` 순서로 묻고 **정리 카드**를 만듭니다. "정리해 줘"라고 하거나 버튼으로 언제든 정리할 수 있고, 질문은 건너뛸 수 있습니다.
- 정리 카드: 내가 보고한 사건, 약속 확인 여부(추측은 추측으로 표시), 공동 기록 확인 여부, 감정, 영향, 필요, 가능한 행동 요청, **사람에 대한 평가를 행동으로 바꾼 표현**, 아직 확인할 점, 반영할 일반 주제. 직접 고칠 수 있습니다.
- 욕설·평가 표현은 정리 카드에 옮기지 않습니다.
- "죽고 싶다"처럼 긴급한 위험 신호가 보이면 흐름을 멈추고 안전 확인과 상담 전화(109, 1577-0199, 112·119)를 먼저 안내하며, 그 대화는 공유할 수 없게 막습니다. "힘들어 죽겠다" 같은 일상 표현은 위험 신호로 보지 않습니다.

**공유 범위와 개인정보**
- 주제마다 `비공개로 두기 / 검토 후 공유 / 허용한 주제로 자동 반영`과 `관련 팀원의 고양이에게 / 팀 공통 약속으로 제안`을 고릅니다. 상대의 고양이가 할 말과 팀 제안 문안을 미리 보여 줍니다.
- 공유 대기함(`shared/outbox.json`)에는 **주제, 미리 써 둔 일반 문안, 공유 범위, 대략적인 주(週)** 만 저장됩니다. 원문·이름·날짜·사건은 들어갈 자리가 없고, 저장 직전에 원문 조각이 섞였는지 한 번 더 검사합니다.
- 건강·가족·연애·돈·성적처럼 민감할 수 있는 내용이 보이면 자동 반영을 막고 검토 후 공유로만 둘 수 있습니다.
- 같은 사람이 같은 주제를 여러 번 공유해도 한 건으로 유지합니다 (여러 명의 의견처럼 부풀리지 않음).
- 대화 원문(`private/conversations.json`)은 이 컴퓨터에만 남고, 보관 기간(7/30/90일 또는 직접 삭제)이 지나면 지워집니다.
- 화면 감시, 키 입력 수집, 메신저 열람은 하지 않습니다.

**AI (선택)**
- 설정에서 Claude API 키를 넣으면 사이의 말이 대화 맥락에 맞게 다듬어지고, 정리 카드가 보강됩니다. 키는 운영체제 보안 저장소(Electron safeStorage)로 암호화해 저장합니다.
- 키가 없거나 호출이 실패해도 규칙 기반 상담 흐름이 그대로 동작합니다. 대화 단계, 안전 확인, 공유 범위 결정은 항상 앱 규칙이 맡고 AI는 문장과 정리 품질만 돕습니다.
- 키를 쓰면 대화 내용이 Anthropic API로 전송된다는 점을 설정 화면에 표시합니다.

## 구조

```
src/
  core/        Electron 없이 테스트 가능한 로직
    behavior.js         고양이 행동 상태 기계
    advice-library.js   조언 모음 (출처 구분)
    advice-scheduler.js 말 걸 때·고를 말·조용한 시간
    topics.js           일반 주제, 행동 요청, 확인할 점, 민감 단서
    language.js         욕설·평가 감지, 감정 감지, 행동 표현으로 바꾸기
    safety.js           위험 신호 감지와 안내
    counseling.js       상담 대화 흐름과 정리 카드
    privacy.js          공유 항목 만들기, 원문 유출 검사
  main/        Electron 메인 프로세스 (창, 트레이, 저장, IPC, AI)
  preload/     렌더러에 열어 주는 최소 API
  renderer/    고양이 창, 대화창
test/core.test.js
docs/development-direction.md
```

개발용: `SAI_SNAPSHOT_DIR=폴더 npm start` 로 실행하면 고양이 상태와 대화 흐름을 차례로 캡처해 PNG로 저장하고 종료합니다.

## 개발 방향 문서 11장 확인 기준 대비

| 기준 | 상태 |
|---|---|
| 고양이가 바탕화면에 보이고 움직인다 | ✅ |
| 클릭해서 개인 대화를 시작한다 | ✅ |
| 불만이 없어도 평소에 명언·조언을 건넨다 | ✅ |
| 욕설·비난 원문을 상대에게 보내지 않는다 | ✅ 구조적으로 원문 저장 위치 분리 |
| 불만의 이유·사실관계·사용자 해석을 확인한다 | ✅ |
| 상대 설명을 듣고 판단을 수정한다 | ◐ "내 사정 이야기하기" 기록까지, 양쪽 연결은 3단계 |
| 인격 평가 대신 행동과 합의를 제안한다 | ✅ |
| 허용한 고민 주제가 일상 조언에 반영된다 | ◐ 공유 대기함·가중치 자리까지, 실제 전달은 3단계 |
| 출처나 다수의 동의를 꾸며내지 않는다 | ✅ |
| 원문·이름·사건 세부가 새지 않는지 점검 | ✅ 테스트 포함 |
| 조언을 줄이거나 거절할 수 있다 | ✅ |
| PR·역량·시간으로 업무 분배 | ⏳ 4단계 |
| 준비물·선행 작업·마감 여유 | ⏳ 4단계 |
| 진행이 막히면 조정 제안 | ⏳ 4단계 |
| 팀원별 계정과 고양이 | ⏳ 3단계 |
| 외부 연결 상태 표시 | ⏳ 5단계 |

## 다음 단계 (3단계: 소규모 팀 연결)

- 팀 만들기·초대, 팀원별 고양이 계정
- 공유 대기함의 `auto` 항목을 상대 고양이 조언 가중치(`advice-scheduler`의 `boosts`)로 전달
- `review` 항목의 확인 화면, `team` 항목의 팀 공통 약속 제안
- 조언 받은 사람의 "내 사정" 기록을 반영해 주제를 보류·수정
- 서버 방식(자체 서버 / Firebase·Supabase 등)과 운영 비용은 아직 정하지 않았습니다.
