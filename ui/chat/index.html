여기서 한 말은 이 컴퓨터에만 저장되고, 원문과 이름은 다른 팀원에게 가지 않아요.

어떤 이야기를 해 볼까요?

팀 약속

누가 제안했는지는 보이지 않아요. 팀원 모두가 동의하면 팀 약속이 돼요.

공유 대기함

다른 팀원의 고양이 조언에 반영될 일반 주제예요. 원문·이름·날짜는 들어 있지 않고, 보낸 시각으로 짐작하기 어렵도록 조금 늦춰 보내요.

나의 대화 기록

이 컴퓨터에만 저장돼요. 보관 기간이 지나면 자동으로 지워져요.

팀 연결

Firebase 콘솔 → 프로젝트 설정 → 내 앱(웹)의 firebaseConfig를 그대로 붙여 넣어 주세요. 팀원 모두 같은 값을 넣어야 해요. 자세한 방법은 저장소의 docs/firebase-setup.md 에 있어요.

버전 · 업데이트

새 버전이 나오면 알아서 받아 두고 고양이가 알려 줘요. "나중에"를 고르면 프로그램을 끌 때 적용돼요.

외부 연결
말 걸기

사이는 업무 도우미라 아예 끄는 기능은 없어요. 회의·발표 중에는 고양이 오른쪽 클릭 → 잠시 조용히(1시간)나 집중 모드(최대 2시간)를 쓰면 되고, 시간이 지나면 저절로 다시 말을 걸어요.

부터 까지
대화 기록
AI 대화 (선택)

Claude API 키를 넣으면 "그냥 이야기할래요"가 일반 Claude 대화처럼 길이 제한 없이 동작하고, 일정 조정도 자유롭게 말해도 알아들어요. 아래 체크는 상담 흐름(속상해요·내 사정)의 문장을 AI로 다듬을지 정해요. 키가 없어도 기본 흐름으로 동작해요. 키를 쓰면 대화 내용이 Anthropic API로 전송되고, 요금은 키 주인 계정에 나가요.

사이가 하는 일

사이의 조언에는 일반적인 협업 원칙과, 팀원들이 공유를 허용한 고민에서 정리한 일반적인 주제가 반영될 수 있어요. 개인 대화 원문과 발언자 이름은 다른 팀원에게 보여 주지 않아요. 다만 두 명뿐인 팀처럼 상황만으로 짐작될 수 있는 경우도 있어서, 완전한 익명을 약속하지는 않아요. 화면 감시, 키 입력 수집, 다른 메신저 내용 열람은 하지 않아요.
