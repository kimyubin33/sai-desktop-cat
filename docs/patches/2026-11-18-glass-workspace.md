# 짧은 문구와 유리 화면

2026-11-18 사용자 요청에 따라 일반 화면의 설명을 줄이고, 먹물 질감 위에 반투명 유리를 얹은 Windows 미리보기로 다듬었다. 상세 사용법과 정보 처리 범위는 [사용 설명서](../user-guide.md)에 모았다.

## 화면 변화

- 파일 버튼은 **PC ↑ / Google ↑ / AI ✧**, 새로고침·다운로드·외부 열기는 아이콘으로 표시한다. 버튼의 접근성 이름과 마우스 설명은 유지한다.
- 팀·협업·설정의 정상 안내를 짧은 상태·횟수로 바꾸고, 반복 설명을 설명서로 옮겼다. 실제 오류와 미전송·읽기 전용 상태는 숨기지 않는다.
- 시작 화면은 **함께, 한곳에. / Google →**로 정리했다. 로그인 후에는 팀 목록을 바로 표시한다.
- 원형·캡슐형 버튼에 반사광·얇은 테두리·눌림 효과를 적용했다. 창과 카드·입력창·대화상자에도 유리 재질을 사용한다.
- Windows 창에 Acrylic 투명 효과를 적용하고, 화면 안에 최소화·최대화·닫기와 도움말을 배치했다. 제목 영역의 기본 이동·두 번 클릭과 오른쪽 아래 크기 조절을 연결했다.
- 작은 창의 배치, 키보드 포커스, 동작 줄이기와 고대비 표현을 CSS에 포함했다. Windows 설정과 그래픽 환경에 따라 유리 표현은 다를 수 있다.

정적 HTML의 SVG·스크립트·스타일을 제외한 텍스트는 2,485자에서 550자로 약 78% 줄었다. 숨겨진 화면·대화상자까지 포함한 정적 문구의 비교이며 동적 오류·실제 자료를 포함한 앱 전체 글자 수의 측정은 아니다. 기존 DOM ID 166개를 모두 보존했고, 추가한 창 제어를 포함해 173개가 중복 없이 존재한다.

## 동작과 권한

이번 변경은 표시와 창 조작에 집중한다. Google 로그인·팀 권한·파일 사본·협업 저장·AI 한도·Calendar의 처리 규칙은 유지한다. 첫 팀 AI 연결의 Google 접근 토큰·Drive 전체 권한 전달 안내와 본문 전송, 재분석 비용, 선택 업무 공유, 일정 추가·수정·삭제 확인을 남겼다.

설명서의 **Google ↑** 항목에는 팀 폴더의 실제 사본 생성과 공유 범위를 설명한다. 팀 AI 항목에는 중계와 Anthropic으로의 본문 처리, 접근 토큰의 권한 범위, 운영자가 기술적으로 원문을 볼 수 없음을 보장하지 않는다는 점을 명시한다. 기기별 개인 AI·로그인 정보와 계정 복원 범위도 구분했다.

도움말은 고정된 GitHub 설명서만 연다. 창 제어 IPC는 현재 작업 창에 한정하고, 새 Tauri 기본 권한도 로컬 `chat` 창의 이동·크기 조정·두 번 클릭 최대화만 허용한다. 외부 페이지나 다른 창에 새 권한을 부여하지 않는다. 제목 영역은 [Tauri 창 사용자 지정](https://v2.tauri.app/learn/window-customization/)의 기본 기능을 사용한다.

## 확인한 범위

- 네이티브 앱 6개·Wasm UI 모듈 2개, 패키지·Google 설정 모의 검사 10개로 **18개 통과**. 이번 UI 변경 뒤 실행한 검사다.
- Wasm 확인과 Windows x64 릴리스·NSIS 설치 파일 빌드 성공.
- 빈 자료 공간에서 실제 초기 화면, 기존 로그인 자료 공간에서 팀 카드·파일·협업·설정과 짧은 버튼·접근성 이름을 확인했다. 같은 PC의 저장된 Google 연결을 재사용했으며 새 인증을 자동 조작하지 않았다.
- 화면의 최소화·최대화·복원·닫기, 제목 영역 두 번 클릭의 최대화·복원을 확인했다.
- 마우스 드래그 이동·오른쪽 아래 크기 조정은 Tauri 기본 명령과 권한까지 연결했으나, 이번 자동 조작에서는 실제 창 좌표·크기 변화를 확인하지 못했다. 실제 마우스 조작과 다양한 Windows 배율·투명 효과 환경의 확인은 남아 있다.

이전 [마무리 검사 259개](2026-11-18-preview-checkpoint.md)는 앞선 체크포인트의 결과다. 이번에 전체 검사를 다시 실행한 수치로 합산하지 않는다. 추가 유료 분석·파일 업로드·팀 초대·업무 저장·Calendar 등록과 운영 정책·Secret 변경은 없다. 허용한 한 팀의 하루 10회 AI 정책을 유지한다.

## 보관과 후속 범위

소스와 설명서는 `work/google-workspace-preview-20261118` 브랜치에 보관한다. 설치 묶음은 `target/Sai-Preview-Glass-20261118-win-x64.zip`이며 설치판·포터블판·체크섬·빌드 정보·읽기 안내만 담는다. 로그인 자료·개인 설정·키·운영 정책·로그는 Git이나 ZIP에 넣지 않는다. 기존 체크포인트 ZIP은 별도 이력으로 유지한다.

ZIP을 다시 열어 다섯 파일의 이름·크기·SHA-256을 원본과 대조했다. 묶음은 **7,919,050바이트**, SHA-256은 `96193b274988ce6baa68b24a58ac5d2c5a8ce988236ac8608e385873a5eb7c75`다. 두 실행 파일의 체크섬과 x64 앱 형식, 연결 정보 포함 여부를 확인했다.

이번 검증판도 0.9.14의 독립 미리보기이며 코드 서명을 하지 않았다. 정식 Releases·기존 제품 자동 업데이트를 발행하지 않는다. 실제 다른 PC의 설치·Google 복원 검증은 사용자 요청으로 계속 보류한다. 다른 CPU·역할·운영 지속성 등 앞선 미검증 범위도 이번 디자인 확인으로 완료 처리하지 않는다.
