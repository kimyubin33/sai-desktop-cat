받은 조언

나의 대화 기록

이 컴퓨터에만 저장돼요. 보관 기간이 지나면 자동으로 지워져요.

기존 서버 톡과 별도의 PC 팀 대화예요. 작성자는 서명된 장치 ID로 표시하며, 기존 계정 이름을 자동 연결하지 않아요. 시각은 작성 PC 기준이고 ‘저장 확인’은 읽음 표시가 아니에요.

팀 연결
팀 서버 선택

서버 PC에서는 http://127.0.0.1:8765 를 입력하세요. 다른 PC에서는 팀 운영자가 알려 준 HTTPS 주소를 사용하세요.

팀 톡·팀 자료 목록·협업 기록은 선택한 팀 서버를 사용해요. Google Drive·캘린더는 각 PC에서 Google에 직접 연결해요. 서버 PC가 켜져 있고 팀 서버가 실행 중이어야 팀원끼리 톡을 주고받을 수 있어요.

Firebase 콘솔 → 프로젝트 설정 → 내 앱(웹)의 firebaseConfig를 그대로 붙여 넣어 주세요. 팀원 모두 같은 값을 넣어야 해요. 자세한 방법은 저장소의 docs/firebase-setup.md 에 있어요.

한 팀에 같은 이름은 한 명만 들어올 수 있어요.

새 팀 만들기

팀을 만드는 사람이 관리자예요. 관리자만 팀원을 내보낼 수 있고, 다른 컴퓨터에서도 이 아이디·비밀번호로 관리자가 돼요. 비밀번호는 다시 볼 수 없으니 기억해 두세요.

PC 연결 실험
같은 네트워크의 PC 연결 확인

자동 호스트를 준비하는 연결 진단이에요. 이번 단계에서는 확인 신호만 주고받으며, 팀 톡이나 파일을 전송하지 않아요. 양쪽 PC에서 실험을 켜고 연결 정보를 서로 등록하세요.

실행하지 않았어요.

상대 PC의 화면과 아래 인증서 지문이 같은지 확인하세요. 다시 시작하면 연결 정보와 지문이 바뀌어요.

이번 실험은 사설 IPv4 LAN을 지원해요. Windows의 앱 통신 허용이 필요할 수 있어요. 게스트 Wi-Fi나 회사 네트워크에서 PC 사이 통신을 막으면 연결할 수 없어요.

PC 팀 장치 등록 준비
내 장치와 관리자 승인 정보

자동 호스트의 신원과 승인 자료를 준비하는 단계예요. 기존 팀을 이전하거나 연결 실험의 권한을 자동 변경하지 않아요. 개인키는 이 Windows 사용자 계정으로 보호해 저장해요.

내 장치를 아직 만들지 않았어요.

운영 관리자 한 명의 키를 모든 PC 팀에서 함께 사용해요. 관리자가 팀을 준비해 승인 정보를 전달하면, 팀원은 관리자 화면과 지문을 대조해 등록해요. 팀원은 등록 요청을 만들어 관리자에게 전달하고, 관리자는 승인 후 갱신된 승인 정보를 돌려줘요.

승인 장치 연결과 암호화된 준비 톡 교환

위에서 선택한 PC 팀의 준비 기능이에요. 저장은 먼저 이 PC에서 완료해요. 별도로 기록 교환에 동의한 양쪽 장치가 암호화 기록 교환을 누르면 준비 톡과 저장 확인을 교환해요. 기존 팀 톡은 아래에서 선택해 이 PC에 별도 보관할 수 있어요. 기존 팀 톡 화면의 서버 연결 전환은 아직 제공하지 않아요.

승인 장치 연결 확인이 꺼져 있어요.

자동 복구는 기본적으로 꺼져 있어요. 개인·도메인 네트워크에서 별도로 선택해 주세요.

자동 연결은 꺼져 있어요.

암호문 중계는 꺼져 있어요. 중계 보관 응답은 최종 수신 확인과 달라요.

대표 PC 선정은 꺼져 있어요. 연결이 나뉘면 PC마다 대표가 다르게 보일 수 있으며, 관리자 권한은 바뀌지 않아요.

자동 연결을 켜면 같은 LAN의 승인된 PC끼리 연결 정보를 확인하고 대기 기록을 이어서 교환해요. 수동 연결에서는 서명된 연결 정보를 서로 등록해요. 기록 교환은 양방향으로 진행하며 한 번에 방향별 최대 8개를 확인해요. 상대가 다른 승인 이력에서 작성한 과거 본문은 자동 교환하지 않아요. 승인 이력이 바뀌면 갱신한 뒤 연결을 다시 시작하세요.

기존 팀 톡 확인·이 PC에 보관

위에서 선택한 PC 팀의 관리자만 사용할 수 있어요. 기존 서버에서 공개 톡을 새로 조회하며, 기존 팀의 현재 관리자 계정도 필요해요. 화면 캐시·개인 문안·파일 링크·약속 제안·연동 설정은 이전하지 않아요.

미리보기만으로 보관하거나 발송하지 않아요.

사이가 하는 일

사이의 조언에는 일반적인 협업 원칙과, 팀원들이 공유를 허용한 고민에서 정리한 일반적인 주제가 반영될 수 있어요. 팀 약속 제안은 내 이름으로 팀 톡에도 올라갑니다. 개인에게 보낸 조언도 작은 팀에서는 상황을 통해 보낸 사람을 짐작할 수 있어요. 화면 감시, 키 입력 수집, 다른 메신저 내용 열람은 하지 않아요.
