팀 연결

Firebase 콘솔 → 프로젝트 설정 → 내 앱(웹)의 firebaseConfig를 그대로 붙여 넣어 주세요. 팀원 모두 같은 값을 넣어야 해요. 자세한 방법은 저장소의 docs/firebase-setup.md 에 있어요.

사이가 하는 일

사이의 조언에는 일반적인 협업 원칙과, 팀원들이 공유를 허용한 고민에서 정리한 일반적인 주제가 반영될 수 있어요. 개인 대화 원문과 발언자 이름은 다른 팀원에게 보여 주지 않아요. 다만 두 명뿐인 팀처럼 상황만으로 짐작될 수 있는 경우도 있어서, 완전한 익명을 약속하지는 않아요. 화면 감시, 키 입력 수집, 다른 메신저 내용 열람은 하지 않아요.
