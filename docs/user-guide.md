# 사이 사용 설명서

사이는 Google 계정으로 팀 파일과 업무를 이어 쓰는 Windows 앱입니다. 앱 오른쪽 위 **?**에서 이 설명서를 열 수 있습니다.

## 시작하기

1. Windows PC에 맞는 설치 파일을 받아 실행한 뒤 **Google →**을 누릅니다. ARM64 PC는 `Sai-Setup-1.0.1-arm64.exe`, x64 PC는 `Sai-Setup-1.0.1.exe`를 사용합니다. [사이 v1.0.1 다운로드](https://github.com/kimyubin33/sai-desktop-cat/releases/tag/v1.0.1)
2. 사용할 Google 계정으로 로그인하고 권한을 확인합니다.
3. 브라우저에서 **사이로 돌아가기**를 누릅니다. 창이 보이지 않으면 작업 표시줄의 사이를 누릅니다.
4. 기존 팀을 열거나 **팀 +**로 만들고, 초대받았다면 **참여**에서 연결합니다.

같은 계정의 팀 목록·내 이름·캐릭터 이름·말 거는 빈도를 불러옵니다. 새 PC는 그 PC에서 로그인합니다. 이전 PC의 로그인 토큰이나 설정 폴더를 복사할 필요는 없습니다. 실제 팀 접근 가능 여부는 현재 Google Drive 공유 권한으로 다시 확인합니다.

바탕화면의 검은 유리 불꽃을 왼쪽 클릭하면 개인 AI를 엽니다. 끌어서 옮길 수도 있습니다. 설정은 프로그램 창 안에 있습니다.

## 버튼 읽기

| 위치·표시 | 동작 |
|---|---|
| 시작 화면의 **Google →** | Google 로그인 |
| 파일의 **PC ↑** | 내 컴퓨터 파일 올리기 |
| 파일의 **Google ↑** | Drive에서 고른 파일의 사본을 팀에 추가 |
| **↓** | 파일 내려받기 |
| **↗** | 해당 자료를 Google Drive에서 열기 |
| **AI ✧** | 선택한 자료에서 할 일 정리 |
| **↻** | 최신 상태 확인 |
| 팀의 **···** | 초대·팀 관리 |
| **?** | 이 설명서 |

아이콘에 마우스를 올리면 이름이 나타납니다. 키보드의 Tab으로 이동하고 Enter나 Space로 실행할 수 있습니다. 창 위쪽 빈 공간을 잡아 이동하고, 오른쪽 위 아이콘으로 최소화·최대화·닫기를 사용합니다.

## 팀과 파일

팀은 Google Drive의 공유 폴더입니다. 소유자는 **··· → 이메일 → 초대**로 팀원을 추가합니다. 초대는 해당 Google 계정에 편집 권한을 부여하며 Google 알림 메일이 전달될 수 있습니다. 초대받은 사람은 같은 계정으로 로그인해 **참여**에서 폴더를 고릅니다.

**Google ↑**는 원본을 유지하면서 팀 폴더에 실제 사본을 만듭니다. 사본은 팀의 현재 공유 권한을 따릅니다. **PC ↑**와 내려받기는 파일당 25MB까지 지원합니다. Google 문서는 Drive에서 엽니다. 파일 목록은 팀 폴더 바로 안의 자료를 표시합니다.

전송이 중단되면 전송 대기의 **결과 확인** 또는 **재시도**를 사용합니다. 대기 삭제는 이 기기의 대기 자료를 정리하며 Drive 원본이나 이미 저장된 사본을 지우지 않습니다. 같은 작업의 재시도는 중복 생성을 막도록 처리합니다.

**목록에서 빼기**는 내 팀 목록만 정리합니다. Drive 폴더·파일·공유 권한은 유지됩니다. 실제 공유 중지는 Google Drive에서 관리합니다. 공유가 해제된 사람의 접근은 다시 검사하지만, 이미 내려받은 사본을 원격으로 회수하지는 않습니다.

## 협업

팀을 고르고 **프로젝트 +** 또는 **할 일 +**로 정리합니다. 제목·담당자·날짜·진행 상태를 저장하면 팀원과 공유됩니다. 담당자 이름은 업무 표시용이며 그 사람에게만 편집 권한을 부여하는 기능은 아닙니다. 실제 읽기·쓰기 권한은 Drive를 따릅니다.

협업 화면은 실행 중 30초마다 새 내용을 확인합니다. 편집 중에는 자동 갱신을 멈추고, 동시에 바뀐 항목은 내용을 비교해 정리합니다. 연결이 끊겨 미전송 변경이 남으면 동기화를 통해 이어 보낼 수 있습니다.

## AI로 정리하기

팀 파일의 **AI** 또는 협업의 **정리 ✧**에서 시작합니다.

1. 자료나 텍스트를 선택합니다.
2. 미리보기에서 실제 보낼 본문을 읽습니다.
3. 전송할 서비스와 내용을 확인하고 **분석**을 누릅니다.
4. 결과의 근거·담당자·날짜를 확인하고 필요한 할 일만 선택해 **추가**합니다.

현재 분석 대상은 Google 문서와 UTF-8 TXT·MD·CSV, 붙여 넣은 텍스트입니다. 본문은 최대 24KiB입니다. AI가 만든 날짜나 담당자는 직접 확인해야 하며, 분석만으로 업무나 일정을 등록하지 않습니다.

선택한 본문은 **사이 팀 AI 서비스와 Anthropic**이 처리합니다. 요약·원문·근거를 팀에 자동 저장하지 않으며, 검토해 선택한 할 일의 제목·담당자·마감일·프로젝트만 협업에 저장합니다. 팀 AI의 공용 키는 운영 서비스에 두고 팀원 PC에 내려주지 않습니다.

첫 팀 AI 연결 때 Google 접근 토큰 전달에 동의합니다. 이 토큰에는 현재 허용한 **Drive 전체 접근 권한**이 포함됩니다. 토큰은 팀 권한 확인에 사용하며, 동의는 기기·Google 계정·서비스별로 보관합니다. Google 비밀번호와 refresh token, Calendar 토큰은 중계에 보내지 않습니다. 운영자가 기술적으로 본문이나 접근 토큰을 절대 볼 수 없는 구조를 보장하지는 않습니다.

협업의 팀 AI 옆 숫자는 **사용 시도 / 일일 한도**입니다. 팀원이 함께 쓰는 한도이며 실패나 응답 유실도 예약한 횟수에 포함될 수 있습니다. 기준 구간은 UTC 하루로, 한국시간 오전 9시에 바뀝니다. 횟수 제한은 금액의 절대 상한이 아닙니다. 분석료는 연결한 API 키의 결제 계정에 청구됩니다. 자동 재분석은 하지 않으며 새 요청에는 비용이 다시 발생할 수 있습니다.

개인 AI 대화는 **AI** 화면에서 사용합니다. Enter로 보내고 Shift+Enter로 줄을 바꿉니다. 개인 AI 연결은 설정에서 별도로 관리하며 키와 개인 대화 기록은 해당 기기에 보관합니다. 개인 대화를 팀에 자동으로 보내거나 새 PC에 자동 복원하지 않습니다.

## 내 일정

협업 할 일의 **일정**에서 제목과 날짜를 확인합니다. 첫 사용에는 본인 Google Calendar를 별도로 연결합니다. **추가**는 본인 기본 캘린더의 종일 일정으로 등록합니다.

이미 연결한 일정은 현재 내용과 비교해 **수정**하거나 **삭제**할 수 있습니다. 일정 삭제는 표시된 내 Calendar 일정만 대상으로 하며 팀의 할 일과 Drive 파일은 유지합니다. 다른 변경이 발견되면 덮어쓰지 않고 다시 확인합니다.

Calendar의 기본 공유 설정에 따라 일정이 다른 사람에게 보일 수 있습니다. 팀장의 로그인으로 다른 팀원의 개인 캘린더를 수정하지 않습니다. 자동 일정 등록·시간 지정 일정·다른 캘린더 선택은 현재 제공하지 않습니다.

## 설정과 자료 보관

- **내 정보**: 이름·캐릭터 이름·말 거는 빈도를 Google 계정에 저장합니다.
- **개인 AI**: 이 기기의 개인 연결과 API 키를 관리합니다. 새 키를 넣지 않으면 기존 값을 유지합니다.
- **개인 대화 보관**: 이 기기의 대화 기록 보관 기간을 정합니다.
- **이전 자료**: 이전 팀·업무·파일 링크의 선택 사본을 내보냅니다. 기존 원본은 유지하고 대화·로그인 정보·키·참여 코드는 내보내지 않습니다.
- **로그아웃**: 이 기기의 Google 연결을 해제합니다. 다른 PC의 로그인은 유지됩니다.

전송·동기화·분석·등록이 실패하면 화면의 오류와 대기 상태를 확인합니다. 빈 목록을 기존 자료의 삭제로 간주하지 않습니다. 로그인이나 권한이 철회·만료되면 다시 연결해야 할 수 있습니다.

## 자동 업데이트

v1.0.0을 쓰고 있다면 v1.0.1을 한 번 직접 설치합니다. 이후 설치판은 실행 직후와 실행 중 3시간마다 새 v1 릴리스를 확인하고, 설치 파일을 내려받아 SHA-256 체크섬을 확인합니다. [사이 v1.0.1 다운로드](https://github.com/kimyubin33/sai-desktop-cat/releases/tag/v1.0.1)

**설정 → 업데이트 확인**으로 바로 확인할 수 있습니다. 준비가 끝나면 **적용하기**를 누르거나 작업 표시줄 알림 영역의 사이 메뉴에서 **종료**를 눌러 설치합니다.

## 미리보기 안내

미리보기는 기존 사이와 별도 앱·자료 공간을 사용하고 시작 프로그램·정식 자동 업데이트에 등록하지 않습니다. 코드 서명과 다른 PC·CPU의 전체 검증은 아직 완료하지 않았습니다. 새 PC 실기기 검증은 현재 보류 상태입니다. [진행 상황](development-direction.md)을 참고하세요.

Windows의 투명 효과와 그래픽 환경에 따라 유리 표현은 다를 수 있습니다. 동작 줄이기·고대비 설정도 고려합니다. 파일·업무·계정 이름과 오류, 전송·삭제 확인은 필요한 시점에 표시합니다.
