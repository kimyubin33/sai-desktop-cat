# 첫 패치 — 먹물 작업 공간과 이전 실행 경로 정리

2026-11-17. [개발 방향](../development-direction.md)의 1단계 진행 기록이다. 제품 전체 전환 완료나 정식 릴리스를 뜻하지 않는다. 버전은 올리지 않는다.

후속 [두 번째 패치](2026-11-17-legacy-preservation.md)에서 아래의 자료 보관·선택 내보내기를 구현하고 1단계 로컬 검증을 마쳤다. 이 문서는 첫 패치 당시의 범위와 검증 기록이다.

## 사용자에게 달라지는 점

- 메뉴를 파일·협업·AI·설정 네 곳으로 줄였다. 기본 화면은 파일 공간이다.
- 제공된 먹물 이미지의 원본을 `ui/chat/assets/ink-texture.avif`로 보관하고 낮은 농도의 배경과 종이 모티프에 적용했다. 외부 이미지 서버에 접속하지 않는다.
- 짧은 화면 전환, 버튼 누름·호버·키보드 포커스 반응을 추가했다. 작은 창에서는 아이콘 메뉴로 줄어들며 `prefers-reduced-motion`에서는 이동 애니메이션을 끈다. 메뉴에 접근성 이름과 현재 위치를 제공한다.
- 개인 자유 대화·이 기기의 이전 대화 읽기·개인 AI 키·설정 저장은 유지한다. 대화를 팀이나 Google Drive로 업로드하지 않는다.
- Google 연결 정보가 포함된 빌드는 기존 로그인 흐름을 재사용한다. 연결 정보가 없는 개발 빌드는 설정 JSON 입력을 요구하지 않고 준비 중으로 표시한다. 로그인했다고 팀 복원이 끝났다고 표시하지 않는다.
- 현재 파일 화면에서는 브라우저로 Google Drive를 열 수 있다. 앱 내부의 팀 파일 업로드·목록·다운로드·초대는 아직 연결하지 않았다. 협업 화면은 예정된 흐름 안내이며 실제 업무 데이터처럼 표시하는 샘플은 없다.

## 걷어낸 실행과 소스

- 팀 톡·PC 톡·장치 승인·LAN 발견·호스트·중계·기기 백업·연결 진단 화면과 IPC를 제거했다. 관련 네이티브 모듈, WebAssembly 화면, 진단 바이너리·빌드 스크립트·전용 의존성과 CI 옵션도 정리했다.
- 앱의 기본 Firebase 백엔드 생성, PC 서버 이전 적용, 시작 시 계정 복원·주기적 팀 동기화·톡 알림·팀 약속과 업무 알림 실행을 제거했다. 기존 Google 계정 백업도 읽거나 덮어쓰지 않는다.
- 공유 AI 키 배포·수신 IPC와 백그라운드 수신을 제거했다. 팀 AI 중계는 구현 전이다. 이미 배포한 키가 원격으로 폐기되었다고 주장하지 않는다.
- 개인 AI·기존 Google 파일/Calendar 로직이 의존하는 이전 `core`의 팀·저장 구조는 일부 남아 있다. 앱에서는 네트워크 백엔드가 없는 Hub만 생성하며, 이전 팀 요청은 IPC 허용 목록에 없다. 다음 단계에서 새 Google 계정·팀 저장소로 교체할 경계를 유지한다.
- Google 로그인에 필요한 일시적인 `127.0.0.1` OAuth 콜백은 사용자가 로그인할 때만 연다. PC 서버나 LAN 발견 기능과 구분한다.

## 자료 보존과 이번 범위의 한계

기존 설정, 개인 대화, 팀 캐시, 공유 대기함, 시간표와 PC 톡 보관 파일을 삭제·이동하는 마이그레이션을 실행하지 않는다. 기존 개인 대화의 보관 기간 정책은 유지한다. 이전 팀 자료를 새 Google 팀으로 자동 게시하거나 기존 계정 백업을 새 형식으로 덮어쓰지 않는다.

첫 패치는 이전 팀 데이터를 새 팀처럼 노출하지 않는다. 자료 보관·선택 내보내기 절차와 기존 설치 자료를 이용한 보존 검증은 1단계의 남은 작업이다. Google 계정별 격리·검증된 계정 식별자·최소 권한·팀 복원은 2단계에서 구현한다.

개인 자유 대화는 기존 Claude 경로와 키 없는 기본 대화를 유지한다. 저장된 OpenAI 연결은 보존하며 이번 패치에서 자유 대화용 OpenAI 경로를 새로 추가하지 않는다. 팀 파일 분석과 공용 AI의 완료로 간주하지 않는다.

## 검증

- WebAssembly 화면 빌드와 Windows x64 네이티브 빌드를 확인한다.
- `cargo test --locked --workspace --target x86_64-pc-windows-msvc -- --quiet --test-threads=4`: 56개 통과, 실제 Firebase 계정이 필요한 기존 검사 3개 제외. 제거한 PC 연결 실험의 테스트 수를 새 기능 검증 수에 포함하지 않는다.
- `SAI_PREVIEW_DIR`로 별도 자료·WebView2 폴더를 사용한 Windows 창에서 파일·협업·AI·설정 전환, 개인 기본 대화 전송·저장, 이전 대화 목록, 설정 저장 완료 표시를 확인했다. 이 모드에서는 고양이 보조 창·시작 프로그램 등록·자동 조언·자동 업데이트를 실행하지 않는다.
- 실제 Google 로그인·권한 승인·두 PC 복원·팀 파일 공유·AI 제공자 호출·Calendar 쓰기는 이번에 시험하지 않는다. 모형이나 준비 화면을 실서비스 검증으로 표시하지 않는다.

## 다음 순서

1. 실제 기존 설치 자료의 보관·읽기 전용 내보내기를 확인하고 1단계 완료 여부를 기록한다.
2. 검증된 Google 계정으로 이름·설정·팀 폴더 참조를 저장·복원한다. 새 PC의 빈 상태로 원격 목록을 덮어쓰지 않게 한다.
3. 실제 팀 공유 폴더와 파일을 연결한 뒤 협업 정보를 붙인다. AI 중계와 Calendar는 그다음 순서를 따른다.
