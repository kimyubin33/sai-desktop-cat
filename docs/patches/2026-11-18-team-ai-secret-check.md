# Claude Secret 확인과 1회 실검증 준비 — 2026-11-18

이 문서는 승인 전 준비 기록이다. 이후 사용자가 실검증을 승인했으며 최신 진행 상태는 [팀 Claude 실검증 진행](2026-11-18-team-ai-live-verification.md)을 따른다.

사용자가 Cloudflare에 `ANTHROPIC_API_KEY` 등록을 완료했다. 첨부 화면과 Wrangler의 Secret 이름 목록에서 필수 Secret 세 개를 확인했다. 값은 조회하거나 출력하지 않았다. 이름이 존재한다는 확인이며 키의 유효성·결제 잔액·모델 접근·실제 분석 성공을 확인한 것은 아니다.

## 확인과 수정

기존 검증 팀의 소유자 식별자를 추측하지 않고 Google Drive에서 확인했다. 일반 Drive 연결 도구는 해당 필드를 생략하므로 개발용 `core/examples/team_ai_owner_info.rs`가 앱의 기존 보호 세션으로 Google 신원과 Drive 소유자 정보를 읽는다. 현재 계정 일치, 사이 팀 표시, 삭제되지 않은 개인 Drive 폴더, 단독 소유와 목록 조회 권한을 모두 확인한다. 토큰 갱신은 메모리에서만 처리하고 실행 전후 앱 설정의 해시가 같아야 결과를 내보낸다. 실제 읽기에서도 계정·소유자 일치와 설정 보존을 확인했다. 식별자·계정별 설정은 Git에서 제외된 `target/team-ai-operator/`에만 보관한다.

검증 모델 초안은 `claude-sonnet-5-5`다. 기본 adaptive thinking 응답과 엄격한 단일 텍스트 결과 검사의 충돌을 피하도록 이 모델에만 `thinking: {type: "between_tools"}`, `output_config: {effort: "low"}`를 지정했다. 도구는 제공하지 않고 기존 출력 한도와 근거 검사를 유지한다. 이는 [현재 모델 문서](https://platform.claude.com/docs/en/models/sonnet-5-5/whats-new-sonnet-5-5)의 도구 없는 텍스트 추출 방식이다. 다른 모델 설정은 바꾸지 않았다. 이 소스 변경은 아직 원격 Worker에 배포하지 않았다.

## 다음 실검증 제안

| 항목 | 준비한 범위 |
|---|---|
| 연결 | 기존 Worker의 기본 `workers.dev` 주소를 검증 중에만 사용. 실제 호스트 이름은 활성화 후 확인 |
| 허용 팀 | 소유자를 확인한 기존 파일 검증 A 팀 한 개 |
| 모델·한도 | Sonnet 5.5, 전체·팀 각각 하루 시도 1회, 최대 출력 1,024토큰 |
| 자료 | 기존 파일 전달 검증용 합성 텍스트 136바이트. 해시로 동일 내용 확인 |
| 변경 | 분석 결과 조회만 수행. 협업 할 일·Calendar에 저장하지 않음 |
| 실패·종료 | 유료 호출 자동 재시도 없음. 시도 또는 실패 후 빈 허용 목록과 비공개 연결로 복귀 |

합성 문서의 내용은 다음과 같다.

```text
SAI file transfer verification
Run: 20261117-083131
This file contains synthetic test data only.
Task: Review the sample by 2026-11-20.
```

전송 대상은 운영자의 Cloudflare 중계와 Anthropic이다. 팀 권한 확인에는 Google 접속 토큰을 중계에 전달하는 기존 구조를 사용한다. 앱의 계정·원점별 동의는 사용자가 해당 안내에서 직접 완료한다. 토큰은 전체 Drive 권한을 포함하므로 자세한 범위는 [신뢰 경계](../../services/team-ai/README.md#신뢰-경계)를 따른다.

[공식 가격](https://platform.claude.com/docs/en/models/sonnet-5-5/overview)은 입력 백만 토큰당 US$2, 출력 US$10이다. 짧은 합성 문서·시스템 지시와 출력 상한을 기준으로 1회 약 US$0.02 이내를 예상한다. 실제 청구액이나 절대 금액 상한을 보장하지 않는다. 하루 시도 제한도 금액 한도와 다르다. 계정별 정책 초안과 실행 계획은 로컬에서 준비·검사했으며 원격에 적용하지 않았다.

기존 승인은 비공개 초기 중계 생성 범위다. 공개 연결과 위 유료 분석 1회는 이 구체적인 계획의 승인을 받은 뒤 진행한다. 현재 허용 팀은 초기 정책의 0개, 공개 연결은 꺼진 상태이며 이번 작업의 실제 Claude 호출은 0회다. API 키 등록을 일반 사용자용 설정 화면으로 추가하지 않았다.

## 검증 결과와 남은 범위

- Node 검사 40개 통과: 중계 모의 18개, 배포 점검 6개, 실제 workerd·SQLite 6개, 패키징 7개, Google 빌드 설정 3개.
- 읽기 전용 소유자 도구의 Rust 검사 2개 통과와 실제 Google 메타데이터 읽기 성공.
- Wrangler 배포 전 빌드 검사 통과. 원격 배포·공개 주소 활성화·실제 유료 호출은 수행하지 않음.

로컬 런타임 검사는 외부 요청을 모두 가로채며 실제 키를 쓰지 않는다. 실제 Claude 응답·키 유효성, 원격 예산 저장소와 앱의 전체 분석 흐름, 다른 팀원의 권한·철회 검증은 남아 있다. 4단계 전체를 완료로 표시하지 않는다.
