# 팀 연결 설정 (Firebase)

팀원 고양이끼리 주고받는 것은 **주제 id, 받는 사람, 주(週), 보류 여부, 팀 약속 응답**뿐입니다. 대화 원문, 정리 카드, 조언 문안은 서버에 올라가지 않습니다. 받는 쪽 앱이 자기에게 들어 있는 일반 문안으로 말합니다.

## 1. Firebase 프로젝트 만들기 (팀에서 한 명만)

1. [Firebase 콘솔](https://console.firebase.google.com)에서 새 프로젝트를 만듭니다. Google 애널리틱스는 꺼도 됩니다.
2. **Authentication** → 시작하기 → 로그인 방법 → **익명**을 사용 설정합니다.
   사이는 이메일·전화번호 없이 익명 계정을 쓰고, 그 로그인 정보는 각자 컴퓨터에 암호화해 보관합니다.
3. **Firestore Database** → 데이터베이스 만들기 → 위치는 가까운 곳(예: 서울 `asia-northeast3`) → **프로덕션 모드**로 만듭니다.
4. Firestore의 **규칙** 탭에 이 저장소의 [`firestore.rules`](../firestore.rules) 내용을 그대로 붙여 넣고 **게시**합니다.
   명령줄을 쓴다면: `npx firebase-tools deploy --only firestore:rules --project <프로젝트ID>`
5. **프로젝트 설정** → 일반 → 내 앱 → 웹 앱 추가(`</>`)를 누르고, 화면에 나오는 `firebaseConfig`를 복사합니다.

`apiKey`는 비밀번호가 아니라 프로젝트를 가리키는 공개 값입니다. 데이터 보호는 4번의 보안 규칙이 맡습니다.

## 2. 앱에서 연결하기 (팀원 모두)

1. 고양이 오른쪽 클릭 → **설정** → **팀 연결**에 복사한 `firebaseConfig`를 붙여 넣고 저장합니다. 팀원 모두 같은 값을 넣습니다.
2. 한 명이 **팀 만들기**를 누르면 6자리 **참여 코드**가 나옵니다.
3. 다른 팀원은 자기 이름과 참여 코드를 넣고 **참여하기**를 누릅니다.

## 3. 연결되면 바뀌는 것

| 기능 | 동작 |
|---|---|
| 공유 범위 정하기 | 주제마다 받을 팀원을 고릅니다. 상대에게 내 이름은 보이지 않습니다. |
| 자동 반영 | 몇십 분~세 시간 정도 늦춰 보냅니다. 보낸 시각으로 누가 말했는지 짐작하기 어렵게 하기 위해서입니다. |
| 검토 후 공유 | 정리함에서 **이 문안으로 보내기**를 눌러야 보냅니다. |
| 받는 쪽 | 받은 주제(최근 3주)를 평소 조언에서 조금 더 자주 다룹니다. 받은 조언인지 아닌지는 말풍선에 드러나지 않습니다. |
| 내 사정도 있어요 | 팀에 연결되어 있으면 모든 협업 조언 말풍선에 나옵니다. 누르면 내 사정 이야기가 시작되고, 정리 후 그 주제의 조언을 멈추거나 팀 약속으로 제안할 수 있습니다. |
| 보낸 쪽 | 상대가 사정을 이야기해 멈춘 주제는 정리함에 "상대가 사정을 이야기함"으로 보이고, 팀 약속으로 맞춰 보자고 제안할 수 있습니다. |
| 팀 약속 | 누가 제안했는지 보이지 않습니다. 같은 주의 같은 주제 제안은 하나로 모입니다. 팀원 모두가 동의하면 팀 약속이 됩니다. |
| 동기화 | 5분마다, 그리고 공유를 저장하거나 설정에서 **지금 동기화**를 누를 때. 마지막 동기화 시각과 오류는 설정에 그대로 표시합니다. |

두세 명뿐인 팀에서는 일반화된 조언이라도 누가 말했는지 짐작될 수 있습니다. 출처 노출을 줄이는 것이지 완전한 익명은 아닙니다.

## 4. 비용

동기화 한 번에 팀원 목록, 팀 약속 제안, 나에게 온 주제, 내가 보낸 주제의 상태를 읽습니다. 앱이 켜져 있는 동안 5분마다 동기화하므로, 작은 팀(대략 5명 이하)이라면 무료(Spark) 요금제 안에서 쓸 수 있는 정도를 목표로 했습니다. 정확한 무료 한도는 Firebase 요금 안내에서 확인해 주세요. 오래된 주제 문서는 아직 자동으로 지우지 않으므로, 오래 쓰면 읽기 횟수가 조금씩 늘어납니다.

## 5. 개발·시험용

**Firebase 없이 한 컴퓨터에서 팀 시험하기 (로컬 시험 모드)** — 같은 공유 파일을 가리키게 하고, 사용자 데이터 폴더만 다르게 앱 두 개를 띄웁니다.

```bash
SAI_TEAM_FILE=/tmp/sai-hub.json SAI_SEND_DELAY_MS=0 npx electron . --user-data-dir=/tmp/sai-A
SAI_TEAM_FILE=/tmp/sai-hub.json SAI_SEND_DELAY_MS=0 npx electron . --user-data-dir=/tmp/sai-B
```

`SAI_SEND_DELAY_MS=0`은 늦춰 보내기를 끕니다 (시험할 때만).

**Firebase 에뮬레이터로 보안 규칙까지 검사하기** — Java와 firebase-tools가 필요합니다.

```bash
npm install -g firebase-tools
npm run test:emulator
```

메모리 백엔드와 같은 계약 테스트(`test/backend-contract.js`)를 실제 Firestore 규칙 위에서 돌립니다.
